📌 Descripción del Proyecto

El presente proyecto consiste en el desarrollo de un calendario dinámico inteligente . El objetivo principal es permitir la visualización automática de fechas, eventos y hitos importantes mediante una interfaz moderna, responsive e interactiva.

El sistema calcula automáticamente los días de cada mes, detecta años bisiestos, identifica el día actual y permite marcar eventos especiales dentro del calendario utilizando JavaScript y CSS Grid.
